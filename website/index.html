📂 Modüller 10 DOKÜMAN

Her kart, o modülün tam kaynak kodu + detaylı analiz sayfasına gider.

🏗️ Proje Kökü (Workspace) Cargo.toml (21 üyeli workspace + tek-sürüm bağımlılıkları), README, install.sh, ai/alerts/risk.toml, CI pipeline. PROJE_KOKU_KAYNAK_KODU.html 🏛️ Cycle Engine (Çekirdek) 5 katmanlı yazılımsal çekirdek: contracts (wire codec), transport (ring buffer IPC), core (simdjson + orchestrator), adapter, splash. CYCLE_ENGINE_KAYNAK_KODU.html 🚀 Execution Engine Binance USDT-M Futures canlı emir yürütme: tek-yazıcı actor, preflight, idempotency, imza, user-data stream → hesap snapshot. EXECUTION_ENGINE_KAYNAK_KODU.html 🧩 Services Engine 8 yardımcı servis: price-feed, calc-ind, detect-ms, ohlcv-engine, stream-ohlcv, alert-service, paper-service (:8080), exec-console. SERVICES_ENGINE_KAYNAK_KODU.html 🎯 Strategies Engine Strateji sözleşmesi (trait_def) ve ilk canlı strateji breakout-strategy: fiyat ring'i → seviye → kırılım → sinyal. STRATEGIES_ENGINE_KAYNAK_KODU.html 🛡️ Risk Engine Merkezi risk motoru: 13 adımlı pre-trade kural zinciri, risk-worker (VaR/exposure/likidite), fail-closed ilke, otomatik kill switch. RISK_ENGINE_KAYNAK_KODU.html 💾 Data Engine Soğuk veri katmanı: cold-storage (kalıcı kapanış verisi) + cold-starter (soğuk başlangıç, EMA hazırlama, replay → canlı geçiş). DATA_ENGINE_KAYNAK_KODU.html 🔧 Additional Services OS-utils (config), scripts (cycle_tmux.sh orchestration, monitor.sh, start/stop_paper, GDPR erasure), k8s chaos, formal verification (TLA+). ADDITIONAL_SERVICES_KAYNAK_KODU.html 🤖 AI Engine LLM ajan katmanı: 3 ajan (sinyal/risk/duygu) paralel karar, koordinatör sentezi, RiskGate doğrulaması, paper/live icra. AI_ENGINE_KAYNAK_KODU.html 🗄️ Unused Services Workspace'ten exclude edilmiş eski detektörler: detect-liquidity, detect-pattern, detect-trb (TRB), detect-wyckoff (faz analizi), scout-service.
